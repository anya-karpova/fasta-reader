# FASTA Reader

Программа для чтения и проверки биологических последовательностей в формате FASTA.

## Описание

Программа содержит два класса:

- `Seq` — хранит биологическую последовательность и её заголовок, позволяет определить длину и алфавит последовательности.
- `FastaReader` — читает FASTA-файлы, проверяет их структуру и возвращает объекты класса `Seq`.

Для чтения используется генератор `yield`, позволяющий последовательно обрабатывать FASTA-записи.

## Возможности

- Чтение FASTA-файлов.
- Чтение нескольких последовательностей из одного файла.
- Определение длины последовательности.
- Определение нуклеотидного или белкового алфавита.
- Проверка структуры FASTA-файла.
- Обработка отсутствующего файла.
- Обработка пустого пользовательского ввода.

## Требования

Python 3.9 или новее.

Для запуска программы дополнительные библиотеки не требуются.

## Установка

1. Перейдите на страницу релиза проекта.
2. Скачайте архив `Source code (ZIP)`.
3. Распакуйте архив.
4. Откройте терминал в папке проекта.

## Запуск программы

Введите команду:

```bash
python3 main.py
```

Программа попросит указать название FASTA-файла:

```text
Введите название FASTA-файла:
```

Например:

```text
sequence.fasta
```

Файл должен находиться в одной папке с `main.py`.

## Пример работы

```text
Введите название FASTA-файла: sequence.fasta
Название: NM_007294.4 Homo sapiens BRCA1 DNA repair associated (BRCA1), transcript variant 1, mRNA
Длина: 7088
Тип: нуклеотидная
```

## Примеры FASTA-файлов

В репозитории находятся:

- `sequence.fasta` — последовательность BRCA1 человека.
- `tp53_mrna.fasta` — нуклеотидная последовательность TP53.
- `tp53_protein.fasta` — белковая последовательность p53.
- `mitochondrion_human.fasta` — митохондриальный геном человека.
- `multiple_sequences.fasta` — файл с несколькими FASTA-записями.
- `invalid.fasta` — файл с неправильной структурой.

## Обработка ошибок

Если пользователь не ввёл название файла, программа попросит указать его.

Если файл не найден, программа сообщит об ошибке и предложит проверить название файла.

Если структура FASTA-файла нарушена, программа сообщит об ошибке чтения.
